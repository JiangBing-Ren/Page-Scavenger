# 贡献者许可协议（CLA）

> 草案。正式启用前建议由律师审定；条款以最终签署版本为准。

## 为什么需要

本项目采用双许可：社区版以 GPL-3.0-only 发布，同时提供商业许可（见 `LICENSE-COMMERCIAL.md`）。
**只有版权持有人才能对外提供商业许可**。如果直接合入未经授权的贡献，项目方将失去对这些代码商业授权的权利。
因此，接受贡献前需要你授予相应的许可。

## 你同意的内容

通过向本项目提交 Pull Request、补丁或其他形式的贡献，你确认：

1. **版权归属**：你保留自己贡献部分的著作权。
2. **授权范围**：你授予项目维护者一项永久、全球范围、非独占、免版税、不可撤销的许可，允许其以任何方式使用、复制、修改、分发你的贡献，**包括以 GPL-3.0 之外的其他许可（含商业许可）再授权**。
3. **原创性**：你的贡献为原创，或你已取得提交所需的全部权利；不包含你无权授权的第三方代码。
4. **无附加条款**：你的贡献不附带与本协议冲突的许可或专利限制。
5. **专利授权**：你授予项目维护者及使用者对你的贡献所必需的专利许可，且不会因你撤回贡献而终止。

## 你不必同意的情况

- 仅提交 Issue、讨论、文档翻译建议
- 仅报告 Bug 或提供复现步骤

## 如何表示同意

在 Pull Request 描述中勾选 CLA 确认项（模板已内置），或书面声明"同意 `docs/CLA.md` 条款"。
