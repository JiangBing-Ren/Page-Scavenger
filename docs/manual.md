## 1. 这是什么

按住鼠标左键划过网页元素，刀光所至直接斩断：高亮框锁定 → 留痕切线 → 对半分离 → 碎片坠落。

它不是「点一下删除」的屏蔽按钮，而是把清理网页做成一次有手感的斩击。三种形态共用同一份引擎（`packages/core`）：

| 形态 | 产物 | 适用 |
| --- | --- | --- |
| 浏览器扩展 | `dist/extension`（Chromium）、`dist/extension-firefox` | Chrome / Edge / Brave / Opera / Vivaldi / Firefox |
| 油猴脚本 | `dist/页面清道夫.user.js` | 已装 Tampermonkey 等管理器 |
| 桌面版 | `packages/desktop`（Electron） | 不想装扩展，或想独立玩 |

## 2. 安装与运行

### 2.1 Chromium 系浏览器

1. 打开扩展管理页（Chrome 为 `chrome://extensions`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择 `dist/extension` 目录
4. 首次加载会自动打开教程关

### 2.2 Firefox

1. 打开 `about:debugging#/runtime/this-firefox`
2. 点「临时载入附加组件」，选择 `dist/extension-firefox/manifest.json`

> 临时载入在浏览器重启后失效。长期使用需要从 AMO 安装签名版本（尚未发布）。

### 2.3 油猴脚本

把 `dist/页面清道夫.user.js` 拖进 Tampermonkey 即可。油猴版不打包音频采样，音效全部走合成音。

### 2.4 桌面版

```bash
npm install      # 仅首次，Electron 二进制约 250MB
npm run build
npm run desktop
```

国内网络慢可在仓库根目录放 `.npmrc`（已被 `.gitignore` 排除）：

```ini
registry=https://registry.npmmirror.com
electron_mirror=https://npmmirror.com/mirrors/electron/
```

### 2.5 从源码构建

只需要 Node.js，构建链零第三方依赖：

```bash
node scripts/build.mjs   # 生成 dist/
node scripts/test.mjs    # 40 项校验：几何、参数、产物、manifest
```

构建会先清空 `dist/`。这一步是有意为之：残留的旧产物会替新产物兜底，导致「本地通过、CI 失败」。

## 3. 基本操作

| 操作 | 效果 |
| --- | --- |
| 扩展弹窗 / 桌面工具栏按钮 | 开关斩击 |
| `Alt+S` | 在当前页快速开关 |
| 页面右键 | 「页面清道夫：开启 / 关闭斩击」 |
| 按住左键划动 | 斩击；**贯穿**目标（从一侧进、另一侧出）才判定命中 |
| 按住期间反复划同一目标 | 叠刀，松手后一次性炸开 |
| `Esc` / 右上角 × | 退出斩击模式 |

### 3.1 贯穿判定

指针必须从目标一侧移入、从另一侧移出，且穿越比例达到目标尺寸的 `pierceRatio`（默认 0.6）才算命中。只在目标内部晃动不会触发。

### 3.2 多刀蓄力（松手炸开）

开启 `多刀蓄力` 后，按住左键期间可对同一目标反复叠刀：

- 单目标最多累积 10 刀（`maxCutsPerTarget`）
- 两次叠刀的最小位移 18px（`minCutGap`），原地抖动不会重复记线
- 松手时按所有切线一次性切成 N+1 块，逐刀展开有节奏（`cutStepBase` / `cutStepDecay` / `cutStepMin`）
- 前几刀只留切线、不碎，表现上是一道道白痕叠上去

### 3.3 连切碎片

切下来的碎片可以继续被切开，每切一次分成两块并向两侧分开。碎块面积低于 60px² 后不再分裂。碎片记录局部多边形与当前变换矩阵，所以旋转飞行中的碎片也能准确切开。设置里可关闭。

## 4. 武器

武器定义在 `packages/core/src/weapons.js`，共 11 种，**目前实现 4 种**：

| id | 名称 | 类别 | 输入 | 计分 | 状态 |
| --- | --- | --- | --- | --- | --- |
| `blade` | 刀 | 近战 | drag | 按面积，单位「刀」 | 已实现 |
| `spear` | 枪 | 近战 | drag | — | 占位 |
| `sword` | 剑 | 近战 | drag | — | 占位 |
| `cannon` | 炮 | 重火力 | click | 按面积，单位「炮」 | 已实现 |
| `revolver` | 左轮 | 枪械 | click | 每发 26 分，单位「发」 | 已实现 |
| `machinegun` | 机枪 | 枪械 | hold | 每发 8 分，单位「发」 | 已实现 |
| `laser` | 激光炮 | 重火力 | hold | — | 占位 |
| `grenade` | 手雷 | 投掷物 | drop | — | 占位 |
| `shell` | 榴弹 | 投掷物 | drop | — | 占位 |
| `snake` | 贪吃蛇 | 特殊 | drag | — | 占位 |
| `blackhole` | 黑洞 | 特殊 | drop | — | 占位 |

输入约定：`drag` 按住拖动（贯穿判定）、`click` 单击一次、`hold` 按住持续生效、`drop` 放置或投掷后延时生效。

### 4.1 刀

按住划动，贯穿后切断。切开的碎片会先露出 2px 缝、停顿 `hitStop` 毫秒，再向两侧飞散——这个停顿是手感的关键，不要随意归零。

### 4.2 炮

点击处范围爆破。以点击点为圆心，用「圆心 + 8 个环点」采样收集半径内的目标（`blastSamplePoints`），避免遍历整棵 DOM。

摧毁分两拍：

1. `spawnBlastCracks`：3~4 条带转折与分叉的裂缝由慢到快逐段生长，每段重算遮罩
2. `spawnBlastBreakup`：裂缝长完后把目标切成多块并逐块崩开

炮是范围武器，**范围内的禁区也会被一起炸掉并扣分**，这是设计意图而不是 bug。

### 4.3 左轮

点一次打一枪，命中光标下的单个目标。弹孔是光滑圆孔并带升腾烟雾（与炮的锯齿裂口区分）。左下角有弹仓指示，打空后自动换弹，换弹期间无法射击；换弹时弹巢旋转，时长与音效对齐（默认 1600ms）。弹壳从光标左下方弹出，落地有独立音效。

### 4.4 机枪

按下点固定为枪口，按住期间朝光标持续扫射。弹孔小而密，带随机散布；枪焰是沿枪口→光标方向的侧视锥形（外橙焰 + 内白焰 + 随机火舌 + 亮核），弹着点有短线弹道。

### 4.5 新增一把武器

1. `weapons.js` 补定义，把 `implemented` 改成 `true`
2. `engine.js` 按它的 `input` 接对应输入分支（`click` 在 pointerdown、`hold` 用 `state.firing` + 渲染循环里的冷却触发、`drag` 走现有贯穿路径）
3. 实现命中与表现，可复用 `spawnDOMFragments` / `reslicePiece` / `spawnSparks`

`setWeapon(id)` 只接受已实现的武器；存储里残留未实现的 id 会自动回退到刀，不会让斩击失灵。

## 5. 计分

### 5.1 自由模式

任意网页开启斩击后，左下角出现计分条：

- 按被切元素面积给分：10 / 20 / 40 / 80
- 900ms 内连续命中累加连击，倍率 `×(1 + 0.25 × (n − 1))`，上限 3 倍
- 退出斩击即重置

自由模式**不判断对错**：任意网页上无法可靠区分「该切」和「不该切」，硬判会产生明显误伤。需要策略性请用关卡。

### 5.2 计分单位

单位跟随武器：刀按面积给分、单位「刀」；炮按面积给分、单位「炮」；左轮每命中 26 分、机枪每命中 8 分，单位都是「发」。

### 5.3 关卡计分

- 面积分档同上（10 / 20 / 40 / 80）
- 连击倍率同上，上限 3 倍
- 禁区每个 −25 分并断连击
- 通关按剩余时间每秒 +2
- 评级阈值由关卡自行声明（`data-grade-s / a / b`），未达标为 C

## 6. 关卡

扩展弹窗点「打开关卡」，桌面版工具栏点「关卡」。目前三关：

| 关卡 | 时限 | 通关分 | 评级阈值（S / A / B） |
| --- | --- | --- | --- |
| 教程关 | 无 | — | — |
| 广告一条街 `ads-alley` | 45s | 300 | 430 / 330 / 240 |
| 卡片丛林 `card-grove` | 60s | 400 | 560 / 420 / 300 |

关卡页机制：

- 目标用 `data-target` 声明，禁区用 `data-decoy`
- 引擎被设成 `targetSelector="[data-target],[data-decoy]"`，只切这两类元素，**不受尺寸挡位限制**——否则满宽广告条会被挡位上限拒绝
- 一刀切中容器时，容器内部的目标全部计分，「自动抓大」因此是双刃剑
- 关卡页禁用「刷新后自动清理」，并且用空存储适配器：**任何可重玩的页面都不能持久化清理记录**，否则第二次进入时目标已被自动隐藏，页面等于空白

## 7. 设置与配置器

扩展弹窗点「高级配置」、桌面版工具栏点 ⚙，打开的是同一套配置页面（`packages/configurator`）。

### 7.1 常用项

| 项 | 说明 |
| --- | --- |
| 尺寸挡位 | 自动智能（向上找最大容器）/ 平衡 / 大 / 中 / 小 |
| 顿感强度 | 无 / 极短 20ms / 短 40ms / 中 80ms / 长 120ms |
| 多刀蓄力 | 按住反复叠刀，松手一次性炸开 |
| 连切碎片 | 切下来的碎片可再次切开 |
| 允许超大容器 | 允许切超出视口比例上限的巨型容器，碎片按可见区域裁剪 |
| 自由切割 | 不限于广告选择器，任意元素都可切 |
| 音效 / 音量 | 总开关与总音量（默认 0.6） |
| 刷新后自动清理 | 记住切过的元素，再次访问同域名时自动隐藏 |

### 7.2 高级参数

按「武器 / 音效 / 多刀 / 判定 / 刀光」分组，顶部可按组筛选，每个字段都能单独重置。

- **武器**：炮的爆破半径、开火间隔、洞口大小与停留；裂缝的粗细/长短/起止宽度；左轮的弹孔、射速、弹仓容量、换弹时间；机枪的弹孔、射速间隔、散布、枪口火光；左轮抛壳开关
- **音效**：11 个效果各自 0~2 的倍率
- **多刀**：单目标最多刀数、叠刀间距、逐刀节奏
- **判定**：搜索深度、目标尺寸上限、贯穿比例
- **刀光**：采样点数、轨迹长度、存活时间、采样步长

### 7.3 预览

- **试切**：用当前<b>未保存</b>的参数直接在配置页里切，`Esc` 退出
- **武器预览**：四个按钮分别触发当前武器的「攻击效果 / 攻击特效 / 音效 / 滤镜」，便于逐项对比
- **重置演示**：恢复被摧毁的演示卡片

预览按钮的 z-index 必须高于斩击画布，否则点不到；预览坐标会校验是否在视口内，视口外 `elementsFromPoint` 返回空，表现为「点了没反应」。

### 7.4 保存与迁移

改动不即时生效，点「保存」才写入；可还原默认，或导出 JSON 到剪贴板（导入用同一份 JSON）。

- 扩展：写入 `chrome.storage`，保存后向所有已打开标签页广播 `adslash:setConfig`（因此 manifest 需要 `tabs` 权限）
- 桌面版：写入用户数据目录下的 `settings.json` 并推给当前页面

## 8. 音效

音效统一走 `sound.js` 的 `play(name)`，共 11 个效果：

刀·挥砍/切入/碎裂、炮·开火/裂缝/爆散、左轮·开火/弹孔/换弹、机枪·开火/弹着、弹壳落地。

**开火音与破坏音是分离的两层**：开火在武器分支播放，命中/摧毁在 `holeDestroy` 里按当前武器播放。

### 8.1 两层播放

能拿到采样文件就播采样，拿不到或解码失败时回落到 Web Audio 现场合成。所以油猴版和桌面版的本地关卡页照样有声，只是听的是合成音。

采样清单位于 `SAMPLE_ASSETS`，逐项声明文件、倍速、音高浮动、响度校准：

| 采样 | 用途 | 原始时长 | 倍速 | 增益校准 |
| --- | --- | --- | --- | --- |
| `shell-drop.mp3` | 弹壳落地 | 0.98s | 1 | 0.6 |
| `revolver-fire.mp3` | 左轮开火 | 2.25s | 1（±8% 随机） | 0.7 |
| `revolver-reload.mp3` | 左轮换弹 | 3.22s | 2（≈1.6s） | 2 |

播放增益 = 总音量 × 倍率 × `gain`，上限 4。校准后的这一档就是配置里的「1」，调音时优先动 `gain`。

逐样本实测峰值：弹壳 1.01、开火 1.10、换弹 1.04——素材本身已超过满刻度，默认总音量下换弹约 1.25，**会削波**。听到爆音先降该采样的 `gain`。

### 8.2 新增一个采样

1. 文件放进 `packages/core/assets/`（构建整目录拷到各宿主）
2. `SAMPLE_ASSETS` 加一条，名字必须是 `play()` 用的效果名
3. 与合成表同名即自动优先采样，不需要改 `engine.js`
4. 扩展的 `web_accessible_resources` 已覆盖 `assets/*`

## 9. 桌面版

`packages/desktop` 是 Electron 外壳，包含内置浏览器与扩展安装导览。

- **内置浏览器**：`WebContentsView` 承载页面，`page-preload` 注入 `packages/core`，与扩展共用同一套手感
- **工具栏**：后退 / 刷新 / 起始页 / 关卡 / 地址栏（可直接输搜索词）/ 开始斩击 / 装到我的浏览器 / ⚙ 配置
- **安装导览**：自动探测本机 Chrome / Edge / Brave / Vivaldi / Opera / Firefox，给出逐步操作，可直接打开对应扩展管理页并复制扩展目录
- **快捷键**：`Alt+S` 开关斩击，`Esc` 退出
- **自检**：`ADSLASH_SELFTEST=1 npm run desktop` 激活引擎并输出 canvas 尺寸、目标数；加 `ADSLASH_SELFTEST_LEVEL=ads-alley` 会模拟一次划动并打印拆解结果；再加 `ADSLASH_SELFTEST_WEAPON=cannon` 会切武器并开一炮

桌面版必须关闭 `backgroundThrottling`：窗口失焦时 `setTimeout` 会被节流到秒级，逐刀序列与碎片动画都会卡住。

打包与 Steam 集成尚未配置。

## 10. 常见问题

**改了代码但没效果**
扩展需要到扩展管理页点「重新加载」；改了 manifest 尤其如此。这是绝大多数「没生效」的原因。

**切不动某个元素**
先看尺寸挡位：挡位有上限，满宽容器可能被拒，改用「自动智能」或打开「允许超大容器」；再看是否命中贯穿要求（要横穿过去，不是在里面晃）。

**切完刷新又出现了**
「刷新后自动清理」把记录存在域名下，只用 `visibility` 隐藏而非删除。要彻底恢复，用弹窗里的「清空本域名记录」。

**撤销上一次**
弹窗里的「撤销上一次」按选择器找回元素、还原切除前的样式并移除记录；可以连续点，会话内最多回退 20 步。

**切大容器时卡顿**
连切每切一次都会重新克隆源元素，切大容器产生的碎片面积大、可连切多轮，DOM 会短时堆积。关掉「连切碎片」或改用更小的挡位。

**没有声音**
浏览器要求先有用户交互才允许播放音频，点一下页面再试；采样缺失时会自动回落合成音，所以不会完全没声。

**配置在重装后丢了**
「加载已解压」的扩展 ID 由安装路径决定，换目录重装会被当成新扩展，存储随之重置。

**Firefox 重启后扩展没了**
临时载入只对当次会话有效，需要签名版本。

**iframe 里的广告切不到**
扩展以 `all_frames: false` 注入，跨域 iframe 内部不会注入，只能整体切外层。

## 11. 开发

### 11.1 架构

```
packages/
  core/          宿主无关引擎（禁止出现 chrome.* / browser.*，测试会断言）
    config.js      手感与判定参数
    engine.js      状态机、事件、渲染循环、武器分发
    weapons.js     11 种武器注册表
    fragments.js   切分、爆破碎块、裂缝、烟雾、弹壳
    pieces.js      碎片注册表与坐标变换（支持连切）
    render.js      刀光、爆痕、枪焰、弹仓、弹壳绘制
    sound.js       11 个命名音效（采样优先 + 合成兜底）
    assets/        音效采样
    score.js / freescore.js  关卡计分 / 自由模式计分
  extension/     MV3 外壳（Chrome / Firefox 双 manifest）
  userscript/    油猴适配层
  play/          关卡运行时与关卡页面
  configurator/  配置界面（扩展 options_ui 与桌面窗口共用）
  desktop/       Electron：内置浏览器 + 安装导览 + 配置窗口
scripts/
  build.mjs      零依赖 ESM→IIFE 打包器
  make-icons.mjs 程序化生成 PNG 图标
  test.mjs       40 项校验
```

宿主只负责三件事：提供存储适配器、决定何时激活、把配置塞进来。任何 `chrome.*` / `browser.*` 出现在 `core/` 都会让测试失败。

### 11.2 约定

- 手感参数以 `config.js` 为准，测试会断言关键值，改动要同步更新测试
- 表现层硬约束：整屏白闪与震屏只在「目标被摧毁」那一刻触发一次，逐刀过程只用静态亮度表示进度；炮的裂缝阶段必须低亮度，提亮会把透明裂缝洗白
- 构建前清空 `dist/`；本地测试绿不等于 CI 绿，改路径或迁文件后要重新全量构建
- 本地是 Node 24，CI 用 Node 22

### 11.3 调试钩子

| 钩子 | 用途 |
| --- | --- |
| `window.__levelDebug()` | 关卡状态（含 `chambers` / `shells`） |
| `window.__levelSetWeapon(id)` | 切武器 |
| `window.__levelWeaponInput()` | 模拟一次当前武器的输入 |
| `window.__configPreview(kind)` | 配置器预览，返回执行结果 |

Electron 的 `sendInputEvent` 在窗口未持续绘制时会被合并成 1~2 个 `pointermove`，测不出效果；交互测试要在页面内 dispatch 合成 `PointerEvent`。
